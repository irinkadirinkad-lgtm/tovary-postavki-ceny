# Товары, поставки, цены — EL'NATUREL

Закупки, приходы, себестоимость и наценки салона и магазина. Источник правды по остаткам
и ценам — YClients (компания 328251).

- `STATUS.md` — живой журнал: правила наценок, грабли, соглашения, открытые вопросы.
- `postavki/<дата>/` — готовые файлы конкретной поставки (карточки товара, приходы).
- `scripts/` — сборка файлов под шаблоны YClients.
- `.claude/skills/` — скил снабженца-закупщика.

Общие правила работы — в репозитории `claude_md`. Доступ к YClients API — скил
`my-skill-yclients-api` там же. Прайсы, бланки и шаблоны поставщиков — Google Drive,
папка «Бланки и заказы».
